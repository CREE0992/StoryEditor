# 仓库维护与发布

建议仓库名称：`branch-game`

## 初始化仓库

将当前目录作为仓库根目录，保留README、LICENSE、源码、examples和tests。使用组织或维护者有权管理的账号发布仓库。发布前核对仓库名称、简介和许可证，排除客户数据与个人工作备份。

## 版本维护

修改后运行测试并验证页面；更新package.json与CHANGELOG中的版本信息。发布时使用真实的维护者、发布日期和贡献记录。
