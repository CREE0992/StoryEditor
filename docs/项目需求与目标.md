# 功能与适用范围

## 互动剧情编辑器

编排剧情节点、条件和选项，校验连接并导出可试玩的网页游戏。

## 输入

- 游戏名称
- 起始节点ID
- 初始变量（每行 名称=整数）
- 剧情节点：节点ID、剧情内容
- 选项与条件：来源节点、选项文字、目标节点、条件（如key>=1）、变量变化（如key+=1）

## 运行与保存

在桌面浏览器中打开index.html。处理过程在本机完成，使用JSON备份保存与恢复数据。

## 功能说明

结构可达检查不证明所有条件组合均可达；循环剧情允许，变量只支持整数、比较和增减，不执行任意代码。

## 验证要求

检查核心计算、无效输入提示、文件导出、备份恢复和界面显示。
